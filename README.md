# DeepGuard AI

A deepfake detection project: an **EfficientNet-B0** classifier (PyTorch) trained to tell real faces from AI-generated ones, wrapped in a **Flask** web app with user accounts, scan history, and image, video and webcam modes.

> **Status: the web app is currently in demo mode.** See [Demo mode](#demo-mode-read-this-first) before presenting or deploying it.

---

## Features

- **Model training pipeline** (`train.py`): transfer learning from ImageNet, data augmentation, AdamW with cosine LR schedule, best-checkpoint saving, final test evaluation
- **Inference code** (`model.py`): face detection and cropping (OpenCV Haar cascade), image prediction, and video prediction by sampling up to 16 frames
- **Web app** (`app.py`): sign up and login, image upload, video upload, webcam frame capture, dedicated result page, per-user scan history
- **SQLite database** created automatically on first run (users and scan history)

## Demo mode (read this first)

In the current `app.py` the model is **not used** when you scan something:

- The calls to `predict_image` and `predict_video` are commented out.
- `_make_response()` overrides the probability with a random value. A file whose name contains `fake`, `ai` or `midjourney` is always reported as **FAKE** (88 to 96%). Everything else, and every webcam capture, is reported as **REAL** (88 to 96%).

So the results shown in the web interface are **not real detections**. This was meant for quick presentations only. Do not use it to judge real content, and say clearly that it is a demo if you show it to others.

### Turn on real detection

1. In `app.py`, inside `analyze_image` and `analyze_live`, replace `prob = 0.0` with:
   ```python
   from model import predict_image
   prob = predict_image(file_bytes)
   ```
2. In `analyze_video`, replace `prob = 0.0` with:
   ```python
   from model import predict_video
   prob = predict_video(temp_path)
   ```
3. In `_make_response()`, delete the block between `# --- PRESENTATION HACK ---` and `# -------------------------` so the real `prob` is used.
4. Make sure `best_model.pth` is in the project root, then restart the app.

## How it works

| Part | Details |
| --- | --- |
| Backbone | EfficientNet-B0 pretrained on ImageNet (first two feature blocks frozen) |
| Head | Dropout 0.3, Linear 256, ReLU, Dropout 0.2, Linear 1 (one logit, `BCEWithLogitsLoss`) |
| Output | Sigmoid of the logit = probability that the image is **FAKE** (fake = 1, real = 0) |
| Input | 224 x 224 RGB, ImageNet normalisation |
| Face handling | Largest face found by Haar cascade is cropped with a 20% margin. If no face is found, the full image is used |
| Video | Up to 16 evenly spaced frames, probabilities are averaged |
| Training aug. | Random crop, flip, rotation, colour jitter, random grayscale, random erasing |

## Dataset

Trained on the Kaggle dataset **140k Real and Fake Faces** (real faces from Flickr-Faces-HQ, fake faces generated by StyleGAN):

| Split | Images | Real | Fake |
| --- | --- | --- | --- |
| train | 100,000 | 50,000 | 50,000 |
| valid | 20,000 | 10,000 | 10,000 |
| test | 20,000 | 10,000 | 10,000 |

`train.csv`, `valid.csv` and `test.csv` list the image paths and labels (`label_str` is `real` or `fake`). The images themselves are **not** in this repository. Download them from Kaggle and extract so the folders look like this:

```
real_vs_fake/real-vs-fake/
├── train/{real,fake}/
├── valid/{real,fake}/
└── test/{real,fake}/
```

If your path is different, change `DATASET_ROOT` at the top of `train.py`.

> **Fast mode:** `train.py` currently trains on a random subset (2,000 train and 500 validation images) for 5 epochs so it finishes quickly. For a properly trained model, remove the `FAST MODE` block in `load_datasets()` and raise `EPOCHS`.

## Project structure

```
deepguard/
├── app.py                 # Flask app: pages, auth, API endpoints
├── model.py               # model definition + inference (image, video, face crop)
├── models_db.py           # SQLAlchemy models: User, ScanHistory
├── train.py               # training and evaluation script
├── create_dummy_data.py   # makes a tiny fake dataset to test the pipeline
├── best_model.pth         # trained weights
├── requirements.txt
├── train.csv / valid.csv / test.csv   # dataset file lists
├── templates/             # landing, auth, detect, result, history (HTML)
└── static/                # CSS, JS, images
```

`app.py` renders `landing.html`, `auth.html`, `detect.html`, `result.html` and `history.html` from `templates/`. Make sure that folder (and `static/`) is included when you upload to GitHub.

## Setup

Requires Python 3.9 to 3.11.

```bash
git clone https://github.com/Fawad1731/deepguard-ai.git
cd deepguard-ai

python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

pip install -r requirements.txt
```

## Train the model

```bash
python train.py
```

The best checkpoint (by validation accuracy) is saved to `best_model.pth`. Training stops early if validation accuracy reaches `TARGET_ACC` (90%). To only test that everything runs, create a tiny dummy dataset first:

```bash
python create_dummy_data.py
```

> The dummy images are plain coloured squares (blue = real, red = fake). A model trained on them learns nothing useful. It is only a smoke test.

If you see DataLoader errors on Windows, set `NUM_WORKERS = 0` in `train.py`. If you run out of memory, lower `BATCH_SIZE`.

## Run the web app

```bash
python app.py
```

It opens `http://127.0.0.1:8000` in your browser. Create an account, then use the Detect page for image, video or live mode.

## API endpoints

All endpoints need a logged-in session.

| Method | Route | Description |
| --- | --- | --- |
| POST | `/api/analyze/image` | Upload an image (`file`) |
| POST | `/api/analyze/video` | Upload a video (`file`) |
| POST | `/api/analyze/live` | Send one webcam frame (`file`) |
| GET | `/api/history` | Last 20 scans of the current user |

Each analyze endpoint returns JSON with `scan_id`, `result` (`REAL` or `FAKE`), `confidence` and a `redirect` to the result page.

## Configuration and security notes

- `SECRET_KEY` is read from the `SECRET_KEY` environment variable. Before putting the app online, set it to a long random value (the default is only for local testing).
- `debug=True` is on. Turn it off in production and run with a real server such as gunicorn.
- Uploaded videos are saved to a temporary file and deleted after analysis.
- Add `deepguard.db`, `venv/`, and the dataset folder to `.gitignore` (a ready `.gitignore` is included).

## Limitations

- Trained on StyleGAN faces versus FFHQ photos. It can miss other generators (diffusion models, face swaps) and heavily compressed or edited media.
- No accuracy numbers are published here yet. After a full training run, add your validation and test accuracy to this README.
- A "REAL" result never proves a file is authentic, and "FAKE" is a probability, not proof.
